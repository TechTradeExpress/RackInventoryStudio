# Rack Inventory Studio — Example Repository v0.1

This is an example repository compatible with the current Rack Inventory Studio data format v0.1.

It demonstrates:

- YAML repository structure,
- hardcoded device_type categories,
- device models,
- concrete device instances,
- rack objects as DeviceModel entries with device_type=rack_object,
- rack placements split into front and rear,
- CSV device import format with required device_type column.
