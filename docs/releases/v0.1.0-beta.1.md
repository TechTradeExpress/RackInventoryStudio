# Rack Inventory Studio v0.1.0-beta.1

**Release type:** Pre-release / beta
**Platform:** Windows x64 only
**Date:** 2026-05-27

---

## ⚠ Beta notice

This is a **beta release** intended for internal testing and early feedback.

- Not suitable for production use without additional validation.
- Windows x64 only — Linux and macOS packages are not provided in this beta.
- The installer is **unsigned**. Windows SmartScreen will show a warning on first
  run. Click **"More info" → "Run anyway"** to proceed.
- No auto-update: to upgrade, download and run the new installer.

---

## What's included

### Location and rack inventory

- Create and manage **physical site locations** (code, name, address, description,
  tags).
- Each location holds multiple **racks** (name, height in U, description, tags).
- Location rows navigate directly to the rack view.

### Rack placement diagram

- **Visual rack unit diagram** as the primary placement surface — no separate table.
- **Drag from the palette** to an open U slot to place equipment.
- **Drag an occupied block** within the diagram to move it to a new U slot.
- **Drag to the palette panel** to unplace equipment from the rack.
- Multi-U height-aware **drop-target preview**: hovered cells highlight green
  (valid) or red (blocked) based on the equipment's height.
- **Placement inspector** in the right sidebar — shows target details, Edit and
  Remove actions.

### Device and device model management

- Full create/edit/delete for **devices** and **device models**.
- **CSV device import** with in-app preview and validation.
- **"Create new device" inline** inside the Place equipment modal — no need to
  leave the workflow.
- **"Create new rack object"** inline inside the Place equipment modal.

### Local Git-backed repository

- Create or open a **local repository** — all data is stored on disk.
- **Git status and commit** from inside the app.
- **Push and pull** (fast-forward only) to/from remote.
- Offline-first: the app works without network access; Git remote is optional.

### Settings — Diagnostics and logs

- View the **active log directory** and **default log directory** paths.
- **Open logs folder** in the OS file manager with one click.
- **Choose a custom log directory** via native folder picker.
- **Reset to default** clears the custom override.
- Log-directory changes take effect after app restart.

## Installation notes

1. Download `rack-inventory-studio-v0.1.0-beta.1-windows-installer.zip` from the
   GitHub release assets.
2. Extract the zip and run `Rack Inventory Studio_0.1.0-beta.1_x64-setup.exe`.
3. If Windows SmartScreen appears: click **"More info"** → **"Run anyway"**.
4. Follow the NSIS installer steps. The app installs to `Program Files` by default.
5. Launch from the Start menu or Desktop shortcut.

**Requirement:** Git must be installed and on `PATH` for repository Git operations
to function. The app will open and manage local repositories without Git, but
commit/push/pull commands require Git on `PATH`.

## Smoke-test checklist

Minimum verification before distributing to beta testers:

- [ ] Installer runs; accept SmartScreen warning.
- [ ] App launches without error dialogs or console windows.
- [ ] Custom app icon visible in taskbar / Start menu.
- [ ] Create a new repository → Git initialized automatically.
- [ ] Add a location → add a rack → navigate to rack detail.
- [ ] Drag a device from the palette to an empty U slot → placement appears in diagram.
- [ ] Move a placed block to a different U slot.
- [ ] Drag a placed block to the palette panel → block removed from diagram.
- [ ] Open **Settings → Diagnostics and logs** → path is shown → "Open logs folder" works.
- [ ] Close the app — no crash.

Full QA checklist: [`docs/BETA_WINDOWS_11_QA_EN.md`](../BETA_WINDOWS_11_QA_EN.md).

## Known limitations

- **Windows x64 only.** Linux packages are planned for a future release.
- **Unsigned installer.** SmartScreen warning is expected on every install until
  code signing is added in a future stable release.
- **No auto-update.** Re-run the installer to upgrade.
- **No EV certificate / Authenticode signing** in this release.
- Repository operations other than fast-forward pull may require CLI Git for
  complex merge/rebase scenarios.
