## Summary

Implemented auto-generated internal `code` fields for all four entity types
(Location, Rack, Device Model, Device). The `code` field is now generated by
the backend when not supplied, is immutable after creation, and is hidden from
all Add/Edit forms. `external_ref` uniqueness is now enforced. CSV import no
longer requires the `code` column. Search now ranks name/label above `code`.

## Risks

- Code generation uses a scan-to-first-available-suffix approach. For repositories
  with thousands of entities this scan is O(n) per-creation. Acceptable for current
  scale; a future index-based counter would be faster.
- Codes generated by the sequence can overlap with codes already present if someone
  manually edits YAML files to use those codes. The check guards against this.
- Existing repositories retain their codes unchanged (backward compatibility).
