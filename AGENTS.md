# Agent workflow

## ChatGPT

Responsible for:

- analysis
- milestone planning
- repair prompts
- PR and review-context review

## Claude Code

Responsible for:

- implementation inside the Docker workbench container
- tests and checks
- `.ai/cc-report.md` updates
- PR creation or updates
- review context generation

## Local AI artifacts

Files under `.ai/` are local work artifacts and should not be committed by default.
